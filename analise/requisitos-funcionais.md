# Requisitos Funcionais

> Extraídos a partir das falas dos stakeholders no documento de elicitação
> (contexto, entrevistas) do Sistema de Gestão de Eventos (Eventus).

| ID | Requisito | Origem (stakeholder) |
|----|-----------|-----------------------|
| RF01 | O sistema deve permitir que participantes visualizem todos os eventos disponíveis em um único lugar (catálogo/listagem de eventos). | Participante |
| RF02 | O sistema deve permitir que participantes se inscrevam em eventos. | Participante |
| RF03 | O sistema deve enviar um comprovante de inscrição ao participante logo após a inscrição. | Participante |
| RF04 | O sistema deve permitir que participantes cancelem sua própria inscrição, sem necessidade de contato com a organização, quando o evento permitir cancelamento (ver RN02). | Participante |
| RF05 | O sistema deve permitir que participantes emitam certificado após a realização do evento. | Participante |
| RF06 | O sistema deve permitir que participantes se inscrevam em múltiplos workshops, impedindo inscrição simultânea em atividades com conflito de horário (ver RN06). | Participante / Organizador |
| RF07 | O sistema deve permitir que organizadores criem e configurem eventos (tipo, vagas, se é gratuito ou pago, se permite cancelamento). | Organizador |
| RF08 | O sistema deve controlar automaticamente o número de vagas disponíveis por evento/atividade. | Organizador |
| RF09 | O sistema deve gerenciar uma lista de espera para eventos que atingirem o limite de vagas. | Organizador |
| RF10 | O sistema deve permitir que organizadores acompanhem as inscrições e gerenciem participantes. | Organizador |
| RF11 | O sistema deve exibir aos organizadores a quantidade de inscritos em tempo real. | Organizador |
| RF12 | O sistema deve permitir que a equipe financeira confirme pagamentos de inscrições pagas. | Equipe Financeira |
| RF13 | O sistema deve permitir que a equipe financeira controle e processe reembolsos, nas situações em que forem aplicáveis. | Equipe Financeira |
| RF14 | O sistema deve liberar (confirmar) inscrições em eventos pagos somente após a confirmação do pagamento pela equipe financeira. | Equipe Financeira |
| RF15 | O sistema deve permitir que palestrantes consultem a programação de suas atividades. | Palestrante |
| RF16 | O sistema deve permitir que palestrantes consultem a lista de participantes inscritos em suas atividades. | Palestrante |

**Observação:** este é um primeiro levantamento, obtido com apoio de IA a
partir do texto das entrevistas. Requisitos que dependem de decisões ainda
não tomadas (ex.: RF04, RF06, RF14) estão referenciados às regras de negócio
correspondentes e às dúvidas registradas em `duvidas-e-lacunas.md`.
